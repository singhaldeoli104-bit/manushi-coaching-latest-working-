## Analysis Methodology

### Using screen-analyzer Skill

**Command:**
```bash
# Use the skill command in Claude Code
skill: "screen-analyzer"
```

**What the skill does:**
1. Reads the entire screen file
2. Extracts all features, components, and interactions
3. Identifies navigation patterns
4. Documents data fetching logic
5. Lists all UI components used
6. Captures business logic
7. Notes dependencies and imports

**Output format:** Each analysis creates a detailed markdown file with:
- Screen overview
- Component hierarchy
- Feature list
- Data flow
- Navigation patterns
- UI/UX elements
- Dependencies

### Quality Checklist for Each Analysis
- [ ] All features documented
- [ ] All components listed
- [ ] Navigation flows captured
- [ ] Data fetching patterns noted
- [ ] UI/UX elements described
- [ ] Dependencies identified
- [ ] Business logic documented
